
# Button Loading Animation 🎯

A simple front-end project that demonstrates how to create a **loading button animation** inside a form using HTML, CSS, and JavaScript.

When the user clicks the submit button, a spinner appears to simulate a loading process. After a short delay, the form resets and the button returns to its normal state.

---

## 🚀 Features

- Responsive form layout
- Custom animated loading spinner
- Button state handling (disable/enable)
- Simulated async submission (2 seconds delay)
- Clean and modern UI design
- Built with vanilla HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (custom styling + animations)
- JavaScript (DOM manipulation)
- Bootstrap 5 (optional styling support)

## ⚙️ How It Works

1. User fills in username & password
2. Clicks **Submit**
3. Button gets disabled
4. Loading spinner appears
5. After 2 seconds:
   - Spinner disappears
   - Button is re-enabled
   - Form is reset
